# Open Source Software Licenses Compliance — NHAI Biometrics

NHAI Biometrics leverages several open-source models, libraries, and frameworks. In compliance with the software distribution guidelines, this file compiles all open-source licensing declarations used inside our codebase.

---

## Compilations Summary

| Library / Model | Primary Owner | License | Use Case |
|---|---|---|---|
| YuNet (libfacedetection) | ShiqiYu | BSD-3-Clause | FeatherFace detection architecture |
| MediaPipe (Face Mesh) | Google | Apache-2.0 | 468 landmark mesh maps |
| MobileFaceNet | sirius-ai | MIT | High-entropy 512-dim embedding |
| Silent-Face-Anti-Spoofing | minivision-ai | Apache-2.0 | Passive depth & texture FAS classification |
| SQLCipher | Zetetic LLC | BSD-3-Clause | Secured local database container |
